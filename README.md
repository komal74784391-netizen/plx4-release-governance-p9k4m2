# PLX-4 Release Governance

This repository tracks release-readiness reviews for the PLX-4 speech platform.

## Conventions

- One open issue per candidate run. Title format: `[Release Review] <run display name>`.
- The issue body must include a fenced ```json block containing the review record.
- A copy of the review record is committed under `reviews/`.
- Reviewers close the issue when the decision has been acted on.
